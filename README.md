A program that picks the funniest original one-line review a dog gives the mailman, from twelve candidates, and writes it to `/output/entry.txt`:

> Five stars: every day at noon I bark, he drops the mail and runs. I have trained him well. I still don't know what his job is, but mine is going great.

## How to run

```sh
python3 main.py
```
